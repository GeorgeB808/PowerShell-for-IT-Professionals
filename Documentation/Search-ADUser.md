# Search-ADUser.ps1

## Purpose

Searches Active Directory for a user by username and displays commonly requested account information.

## Commands Used

* Read-Host
* Get-ADUser
* Select-Object

## Skills Demonstrated

* Active Directory administration
* Interactive PowerShell scripting
* User account lookup
* Help Desk troubleshooting

## Real-World Use Case

A Help Desk technician receives a call from a user who cannot sign in. Before resetting the password or escalating the issue, the technician verifies that the account exists, checks whether it is enabled, and confirms key account details.

## Future Improvements

* Search by display name
* Search by email address
* Export search results
* Search multiple users from a CSV file
