# New Employee Onboarding Automation

## Overview

This project demonstrates how PowerShell can simplify the process of onboarding a new employee in an Active Directory environment.

## Objectives

* Collect employee information
* Generate a username
* Prepare an Active Directory account
* Demonstrate the user creation workflow
* Document each step of the automation process

## Skills Demonstrated

* PowerShell scripting
* Active Directory administration
* User provisioning
* Help Desk procedures
* IT documentation

## Real-World Scenario

When Human Resources hires a new employee, IT creates the user's Active Directory account, assigns permissions, and prepares access to company resources. This project models that workflow in a Windows Server lab environment.
